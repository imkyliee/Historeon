# Historeon

Historeon: A Three-Dimensional Adventure Game for Learning Historical Caves and Artifacts in the Philippines aims to support those who want to study history, many of whom often perceive history as difficult, overwhelming, or intimidating. Historeon serves as a supplementary learning tool that complements traditional methods such as lectures, handouts, and textbooks by offering an interactive and entertaining environment where students can learn at their own pace.
